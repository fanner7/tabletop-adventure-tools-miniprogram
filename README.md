一个微信小程序，为桌面角色扮演游戏（TTRPG）玩家提供角色生成、游玩记录和主持辅助工具。

## 🖥️ COC 守密人助手 — 桌面全屏适配

「COC 守密人助手」页面已适配 PC 端大屏（Windows / macOS 微信，`app.json` 中 `resizable: true` 已开启大屏模式）：

- **自动识别**：窗口宽度 ≥ 720px 且高度 ≥ 500px 时自动切换为全屏布局；拉窄窗口自动回到手机窄条布局
- **全屏布局**：模块化自由面板工作台——调查员、NPC 与所有工具（掷骰、战斗轮、疯狂发作、线索表、团务笔记、随机生成、词汇表、规则速查、导入导出）都是内容自伸缩的模块，按**瀑布流**贴紧排布成多列（每个模块紧贴同列上一个模块，长模块不会把其他列顶出空档），带团时一眼全览
- **可拖拽**：按住模块标题栏右侧的 `⠿` 手柄可在瀑布流中任意拖拽换位（其他模块实时让位）；点击标题可折叠/展开；布局与模式自动保存，「↺ 重置」一键还原
- **手动切换**：右下角悬浮栏可强制切换「自动 / 全屏 / 窄条」模式，并可一键重置布局（布局与模式自动保存）
- **顶部补偿**：个别 PC 上微信窗口装饰会遮住页面顶部，用悬浮栏「顶+ / 顶−」微调（按 rpx 随窗口宽度等比，自动保存）；悬浮栏同时显示窗口/视口/状态栏诊断数字
- **测试方法**：
  - 开发者工具：模拟器选择「自定义设备」，把宽度调到 720px 以上（如 1280×800）即可预览宽屏布局
  - 真实 PC 微信：打开小程序后直接把窗口拉宽/最大化，或点右下角「🖥 全屏」强制切换

手机端（iOS / Android / 窄窗口）完全保持原有窄条 UI，不受影响。

## 🐙 COC 调查员工具 — 建卡体验升级

- **草稿自动保存**：创建中途自动落盘（本地 `coc7_draft`），首页出现「继续上次未完成」卡片，一键回到离开时的步骤；保存角色后自动清理草稿，误触「新建」会先确认是否覆盖
- **步骤指示器可跳转**：已完成/到达过的步骤点击即可回跳（未解锁步骤不能跳），跳转到完成页同样执行点数/专攻/信用评级校验
- **可选建卡法**：标准 3D6 之外，支持「英雄 4D6 舍最低」与「点数购买」（8 项属性共 460 点、每项 40-90，官方可选规则），LUCK 自动掷骰
- **建卡期规则速查**：步骤条右侧「📖 规则」随时打开守密人帷幕式速查（检定/战斗/伤害/理智/追逐）
- **信用评级透明化**：职业自动把兴趣点填入 CR 时，卡片上明确说明用了多少点、填到多少
- **常驻校验条**：技能页顶部即时显示剩余/超出的点数与专攻缺失，不用再靠弹窗猜
- **轻量使用提示**：每一步一句单行提示（掷骰可单项重掷、±5 快捷加点等），不遮挡角色卡主体
- **分享卡片**：完成页「🖼 分享卡片」用 canvas 生成暗色角色卡图片（属性/衍生值/技能/武器），预览后可长按保存分享
- **顺手修复**：新建角色不再残留上一个角色的武器与背景文本；编辑已保存角色后新建不会再覆盖旧存档

## 🧪 工程与测试

项目无 npm 依赖（原生小程序框架），测试直接用 Node 运行：

```bash
npm test            # 或 node tools/test/run.js
```

测试套件位于 `tools/test/`，覆盖三层：

- **流程回归**（`coc7-gen.test.js`）：用 Page 桩 + wx mock + 真实数据跑 COC 调查员工具全流程——建卡（掷骰/购点/4D6/年龄修正）→ 114 职业点数计算 → 技能分配（75% 封顶/解除限制）→ 完成页衍生值 → 草稿存取 → 存档往返 → 步骤跳转 → 规则速查 → 自由槽分组 → 游玩模式数据流
- **数据完整性**（`data-integrity.test.js`）：技能/职业/武器/预置角色的唯一性、字段合法性与交叉引用校验（曾揪出"生存"技能缺失、括号条目拆裂等 12+ 处真实数据缺陷）
- **静态检查**（`static.test.js`）：全部页面 JS 可加载、WXML handler 引用完整、标签平衡

改动页面后建议先跑一遍 `npm test` 再提交。
